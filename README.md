# interactor-character-concept-acclaim

Generated full-body character concept illustrations with their prompts and captions, and a declarative model config for scoring them.

## What it is for

It collects generated concept images with the prompts that made them and automatic captions, and sketches a classifier that predicts tags and a rig category from an image. It is work in progress.

## Build and run

The `justfile` holds the install, train and evaluate recipes. Training reads an exported score sheet that is not in the repository.
